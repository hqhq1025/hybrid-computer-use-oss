## Integration correction

The original excerpt code suppressed text whenever the canonical description
contained the value. The renderer can suppress that description or clip away
the value. The extracted code checks the actual displayed fields instead.
It repairs invalid UTF-8, bounds excerpts, avoids repeated visible text, and
leaves canonical properties unchanged. Existing matched-text output takes
precedence over the additional excerpt.
